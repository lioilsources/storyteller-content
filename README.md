# storyteller-content

Stahovatelný obsah aplikace StoryTeller (balíčky pohádek podle zemí a kontinentů).

- `docs/` — GitHub Pages: `manifest.json` (katalog balíčků, verze, sha256, velikosti) a náhledy.
- Zipy balíčků jsou v **GitHub Releases** (`pack-<id>-v<N>`), ne v gitu.

Publikuje se z pipeline v repu `storyteller` (`rag/publish_packs.sh`), ručně se tu nic needituje.
Plán: `storyteller/STORYTELLER_MONETIZATION_PLAN.md`.
